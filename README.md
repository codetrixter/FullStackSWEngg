### Directory -  binaries_for_grpc_and_protobuf:

- Two directories are present inside the **binaries_for_grpc_and_protobuf** folder
  - grpc
  - protobuf
  
  Note : Inside the above 2 directories "binaries" are present for grpc and protobuf which we can use it in our project directly by giving the path - lib,bin,include
  
### Directory - code_for_grpc_and_protobuf:

-  Code are present for GRPC and Protobuf for respective version v1.65.1 and 21.12 (libprotoc 3.21.12)

### Directory - GRPC_BOOKSTORE_PROJECT

- Sample application of Bookstore using client-service gRPC and protobuf libraries (where are the project configuration done).

### getfilename.bat:

- To generate the libraries name : open and update the source and destination path - once executed successfully it will generate output.txt file.

### output.txt:

- Demo output.txt file with content all the lib files generated by getfilename.bat file 


### readme_project_configuration.md: 

-  Bookstore project configuration file.

### readme_setup_for_GRPC_and_Protobuf.md:

-  GRPC and Protobuf code clone and build it : Freshly clone and build.

  
### How to use in project: Configure/Add for both Client and Server
  
  ** Configuration of project properties ? **

   ## Project Properties Configuration

		#  C/C++ -> General -> Additional Include Directories 		
  
			create one build directory at project location : mkdir build
			Add the following paths:
				C:\GRPC_SETUP_DEPENDENCY\binaries_for_grpc_and_protobuf\protobuf\include 
				C:\GRPC_SETUP_DEPENDENCY\binaries_for_grpc_and_protobuf\grpc\include
				<project_location_path>\build (e.g., C:\GRPC_BOOKSTORE_PROJECT\build)

		#  Linker -> General -> Additional Library Directories

			Add the following path:
			C:\GRPC_SETUP_DEPENDENCY\binaries_for_grpc_and_protobuf\grpc\lib
		
		#  Linker -> Input -> Additional Dependencies - Libraries name you can generate through getfilename.bat file 
		    
			*** getfilename.bat file path - C:\GRPC_SETUP_DEPENDENCY\getfilename.bat 
			
			*** Note : Above file generate the "output.txt" file. you can copy all the file name at paste it to below location  
			    Linker -> Input -> Additional Dependencies
		 
			 You can verify the library names by running "getfilename.bat" in the C:\GRPC_SETUP_DEPENDENCY\binaries_for_grpc_and_protobuf\grpc\lib\ directory and updating as needed.  
			 Add libprotobuf.lib also - C:\GRPC_SETUP_DEPENDENCY\binaries_for_grpc_and_protobuf\protobuf\lib\libprotobuf.lib
